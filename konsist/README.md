# :konsist

Архитектурные тесты уровня **классов и файлов** — то, что нельзя выразить графом модулей.

## Зачем отдельный модуль

В проекте уже есть две проверки архитектуры, но обе работают на уровне модулей:

| Инструмент | Уровень | Что проверяет |
|---|---|---|
| `:app:assertModuleGraph` (`com.jraska.module.graph.assertion`) | граф модулей | высота графа, отсутствие запрещённых рёбер |
| `soft.divan.check.conventions` (`CheckConventionsPlugin`) | модуль | какие convention-плагины применены, `core` не зависит от `feature`, `impl` не зависит от `impl` |
| **`:konsist`** | класс / файл / пакет | где лежит класс, как он назван, чем аннотирован, что импортирует |

Модуль тестовый: продуктового кода не содержит и ни от кого не зависит — поэтому не
появляется в графе `:app` и не влияет на размер APK. Konsist сам обходит исходники
всех модулей, читая их с диска.

## Правила

Тесты в [`ArchitectureKonsistTest.kt`](src/test/java/soft/divan/financemanager/konsist/ArchitectureKonsistTest.kt)
кодифицируют архитектурные требования проекта (см. [`docs/agents`](../docs/agents)):

* UseCase — имя `*UseCase`, живёт в `..domain..`.
* Репозитории — интерфейс в `..domain..`, реализация `*RepositoryImpl` в data-слое.
* Room `@Entity` не выходит за `:core:database`, DTO — за `..dto..`-пакеты.
* `java.util.Date` / `Calendar` запрещены (дублирует кастомный lint-чекер `OldDate`).
* ViewModel — имя `*ViewModel` и аннотация `@HiltViewModel`.
* Scope непустой — страховка от «зелёного» прогона, который ничего не проверил.

Требования, которые здесь **не** формализованы (сегодня в коде есть отступления,
их нужно сначала разобрать):

* инъекция `CoroutineDispatcher` вместо `Dispatchers.IO` / `Dispatchers.Default` —
  7 мест, часть из них осознанные (провайдер в `AppModule`, значения по умолчанию
  у `safeApiCall` / `safeDbCall`);
* единое имя пакета презентационного слоя — сейчас соседствуют `presenter` и `precenter`.

## Запуск

```bash
./gradlew :konsist:test
```

Правило, которое перестало выполняться, — это либо баг, либо осознанное изменение
конвенции: во втором случае правится тест, а не подавляется падение.
