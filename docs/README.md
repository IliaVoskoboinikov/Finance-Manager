## Как писать документ

- Порядок разделов: заголовок → 2–3 строки о том, что описано и для кого → схема →
  содержательные разделы → «Решения и почему» → «Ограничения» → «Связанные задачи» →
  «Ключевые файлы». Раздел, которому нечего сказать, не пишется.
- Оглавление руками не пишется — GitHub строит его сам.
- Документ описывает, как устроено и почему. Задачи и чек-листы открытой работы — на доске;
  документ ссылается на карточку: `[FM-42](https://github.com/IliaVoskoboinikov/Finance-Manager/issues/42)`.
  Короткая запись `#42` в файлах репозитория ссылкой не становится.
- Новый документ добавляется в этот каталог в подходящий раздел.
